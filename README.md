## 🎮 ゲーム概要

AI対戦型の人狼推理ゲームです。プレイヤー1人＋AI最大8人で、怪しい相手を疑い・かばい・嘘を見破ることを目指します。現在5人モード（人狼1・狂人1・占い師1・村人2）が公開済み。9人モード（霊媒師・騎士追加）を開発中、13人モード（妖狐追加）を構想中です。

## 🧠 設計思想①：人狼を「HP」で再現する

### なぜ「HP」か

既存タイトル（グノーシア等）のアプローチをそのまま採用すると独自性がなくなります。そこで「怪しい相手を疑い、嘘を見破る」という抽象的な読み合いを、**HP・ダメージ・回復という直感的な構造**に翻訳しました。

- HPが低いキャラほど嘘がバレやすい
- 「疑う」＝ ダメージ、「かばう」＝ 回復

### HP = calm（平常心） + like（好感度）

| 要素 | 役割 |
|---|---|
| **calm** | キャラごとに初期値が異なる基礎HP |
| **like** | キャラ間の好感度（視点付き）。疑うと下がり、かばうと上がる |

likeは視点付き（Aから見たB、Bから見たAを別の値として管理）なので、「Aは Bを信頼しているが、BはAを信頼していない」という非対称な人間関係が成立します。この合計値を**知覚平常心**と呼び、低い順に下位2人が観測フェーズの対象として選ばれます。

### 観測フェーズ：仕様書から実装への変換例

以下の日本語仕様書をClaudeに渡してコードへ変換させています。**ロジックの設計・意思決定はすべて自分が行い、Claudeはその翻訳のみを担当しています。**

```
f.aliveを確認し生存キャラに対して、知覚平常心（f.calm + f.like）を取得する
知覚平常心の下位2人に対して以下の処理を行う

視点キャラの観察力（ハードコード）- 知覚平常心 = 差分

差分 ≦ 0 → 観測失敗（処理終了）
差分 > 0 → f.characterを参照し対象が人狼陣営（< 10）か確認

人狼陣営でない → 観測失敗（処理終了）
人狼陣営 → （観察力 ÷ 5 + 差分 ÷ 2）÷ 100 の確率で抽選

外れ → 観測失敗。対象へのlike（好感度）を加算する
当選 → 視点キャラのf.liarの該当枠に1を代入
       f.player視点の当選時はtargetにliar、ai_resultに当選キャラ番号を格納
```

失敗時にlikeを加算するのは「やっぱり違うかも…」という心理の表現で、同じキャラへの観測が固定化されることを防ぐ仕組みでもあります。

### liar：キャラごとに異なる「知っていること」

liar変数は各キャラ視点での「誰が嘘をついているか」の認識を視点ごとに個別管理しています。全キャラが同じ情報を共有する「神視点」ではなく、**見えている情報がキャラごとに異なる**ことで、AI同士が個別に間違えたり疑心暗鬼になったりする人間らしい推理が生まれます。

## 🏗️ 設計思想②：拡張性を見据えた構造

### キャラごとの値はすべて配列で一元管理

役職は `f.character`、平常心は `f.calm` という1本の配列で管理。配列の長さを伸ばすだけで人数を増やせます。

```javascript
function getRole(i){ return parseInt(String(f.character).split(',')[i-1]); }
function getCalm(i){ return parseFloat(String(f.calm).split(',')[i-1]); }
```

### 役職番号は「桁」が陣営を兼ねる設計

| 役職 | 番号 | 陣営 |
|---|---|---|
| 人狼 | 1〜5 | 人狼陣営 |
| 狂人 | 9 | 人狼陣営 |
| 占い師 | 10 | 村人陣営 |
| 霊媒師 | 11 | 村人陣営 |
| 騎士 | 12 | 村人陣営 |
| 村人 | 15〜（連番） | 村人陣営 |

```javascript
function isWolfTeam(role){ return role < 10; }
```

一桁が人狼陣営、二桁が村人陣営という区切りにより、新しい役職を追加しても陣営判定ロジック自体は変更不要。liar・like配列のサイズも `n×(n-1)` という汎用式で導出できます（9人=72値、13人=156値）。

## 🛠️ 技術スタック・ファイル構成

| 分類 | 使用技術 |
|---|---|
| ゲームエンジン | [TyranoBuilder](https://tyranobuilder.com/)（ノベルゲームエンジン） |
| ロジック・AI実装 | JavaScript（iscriptコンポーネント） |
| 状態管理 | TyranoBuilder標準のセーブ機能（外部ファイル・外部DB不使用） |
| 公開 | GitHub Pages |

会話パートはTyranoBuilderに任せ、数値管理・AIロジックだけをiscriptで自作する役割分担です。

### ファイル構成

| ファイル | 役割 |
|---|---|
| `start.ks` / `tutorial.ks` | プロローグ・チュートリアル |
| `role.ks` / `scenario.ks` | 役職決め・ストーリー進行 |
| `system.ks` / `end.ks` | 初期化・死亡処理・ターン終了判定 |
| `debate.ks` / `AI.ks` / `UI.ks` | 議論フェーズ・AI行動・UI |
| `doubt.ks` / `cover.ks` / `observe.ks` | 疑う・かばう・観測処理 |
| `co.ks` / `uranai.ks` / `say_human.ks` | CO・占い・「人間と言え」処理 |
| `vote.ks` / `night.ks` | 投票・夜フェーズ（襲撃・占い・霊媒・守護） |
| `キャラ名.ks` | 各キャラクター個別の台詞 |
